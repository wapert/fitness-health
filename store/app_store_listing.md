## 描述（Description）
```
全方位健身把你需要的訓練工具集中在一個 App —— 從重量訓練到伸展、超慢跑、飲食營養與斷食，還能規劃每週計畫並雲端同步。

【重訓】
• 依肌群瀏覽：胸、背、臀、大腿、小腿、手臂、核心
• 每個動作附示範影片、步驟說明與訓練提示
• 一鍵把動作加入每週訓練計畫

【伸展】
• 對應各肌群的伸展動作，附示範影片與停留秒數

【超慢跑】
• Niko-Niko 個人配速計算器（依年齡估算心率區間）
• 步頻節拍器，協助維持 180 BPM 標準步頻
• 內建循環伴跑音效（雨聲、海浪、風聲、白／粉紅／棕色噪音），離線可用

【飲食營養】
• 依目標（增肌／減脂／減肥／斷食）提供每日巨量營養建議
• 精選餐點食譜，附食材、作法與營養資訊

【斷食計時器】
• 支援 16:8、18:6、20:4、OMAD、5:2 等常見協議

【訓練計畫 + 日曆】
• 設定每週各項活動次數，系統自動安排
• 可拖曳調整、逐日打卡、追蹤每週進度
• 登入後跨裝置雲端同步

【肌群地圖】
• 互動式人體肌肉圖，點擊肌群即可查看對應動作

適合任何想要有系統地變強、變健康的人。現在就開始打造你的專屬計畫！
```

## App 審核資訊（App Review Information）
- **登入帳號**：審核員需要一組測試帳號才能通過登入頁。請在 App Store Connect 的「App 審核資訊 → 登入資訊」填入一組你建立的測試 Email / 密碼。
- **備註（Notes）建議填**：
```
This app requires an account to sync training plans. A test account is provided
above. Video demos open via the YouTube IFrame player. Ambient sounds are
generated on-device (no network). No special hardware required.
```

## App 隱私（App Privacy，資料蒐集揭露）
在 App Store Connect「App 隱私」填寫：
- **蒐集的資料類型**：聯絡資訊 → **電子郵件地址（Email Address）**
  - 用途：**App 功能（App Functionality）**（帳號登入與同步）
  - 是否連結身分：**是（Linked to the user）**
  - 是否用於追蹤：**否**
- **使用者內容 / 其他資料**：訓練計畫與完成記錄儲存在 Firebase Firestore，屬於「App 功能」用途，連結身分、非追蹤。
